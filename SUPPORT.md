# Support

Read Aloud is a manual macOS desktop beta. For reproducible installation and
runtime problems, open an issue at
https://github.com/Heartkemy/heartkemy-read-aloud/issues with:

- Obsidian, macOS, Node, and plugin versions;
- the manual-install step that failed and its error output; and
- whether the macOS `say` voice or optional neural voice was selected.

Do not include vault contents, note text, audio cache files, access tokens, or
other private information. Security reports belong in
[SECURITY.md](SECURITY.md), not a public issue.
