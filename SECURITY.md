# Security policy

The current `0.1.x` manual desktop beta on `main` is supported for security
reports. The plugin and sidecar are intended for one local desktop user only;
they are not a remote service.

Use GitHub's private vulnerability-reporting form for this repository:
https://github.com/Heartkemy/heartkemy-read-aloud/security/advisories/new

Include a minimal synthetic reproduction, affected version, and impact. Do not
include vault contents, note text, recordings, access tokens, or model caches.
Please do not disclose a vulnerability publicly before maintainers can assess
and coordinate a fix.
